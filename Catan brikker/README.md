Legg ressursbrikke-bildene her (PNG/JPG/WebP):

- Tømmer → kopieres til `wood.png`
- Tegl → `brick.png`
- Ull → `sheep.png`
- Korn → `wheat.png`
- Malm → `ore.png`
- Ørken → `desert.png`

Kjør deretter fra `catan-generator/`:

```bash
npm run copy:tiles
```

Mappen kan også ligge i prosjektroten (`../Catan brikker`).
