# Native assets

Place App Store / Capacitor assets here before shipping:

- `icon-1024.png` — App Store icon (1024×1024, no transparency)
- `splash.png` — splash background (optional; Capacitor SplashScreen uses config color until set)

Generate Xcode asset catalogs on a Mac with:

```bash
npx @capacitor/assets generate --ios
```

Use generic hex-island artwork — not official settlers / Catan product art.
