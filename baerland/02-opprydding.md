# Fase 2: Umiddelbar opprydding

Gjør dette nå (juli/august), mens du fortsatt har oversikt etter luking.

## Begge arealer

- [ ] Fjern råttent plantemateriale fra bakken (forebygger gråskimmel og sopp)
- [ ] Fjern luket ugress fra bedet — legg det i kompost/bunt, ikke la det ligge i raden
- [ ] Rydd bort døde blader og knuste bær

## Bringebær — mens du høster

1. [ ] Høst modne bær fra de **brune kanene**
2. [ ] Bind inn **grønne kaner** på støttetrådene
3. [ ] Fjern bare **tørre, døde eller syke** kaner (knelete, sprukne, helt bladløse)
4. [ ] Tre ut kaner som vokser langt utenfor raden — bind inn hvis de er friske, ellers fjern

## Bringebær — etter avlingen er over

1. [ ] Klipp **alle brune kaner helt ned til bakken**
2. [ ] Tell: behold **6–8 sterke, grønne kaner per løpemeter**
3. [ ] Klipp bort overskytende grønne kaner (de svakeste/tynneste)
4. [ ] Bind de gjenværende grønne kanene pent inn langs trådene

> **Viktig:** Ikke klipp grønne kaner under høsting — det er neste års avling.

## Jordbær — rydding nå

1. [ ] Marker ønsket bed-grense med snor, stolper eller en enkel kant
2. [ ] Grav opp og fjern **alle planter utenfor grensen** (inkl. rotfestede utløpere)
3. [ ] Fjern de **svakeste og sykeste** plantene innenfor bedet
4. [ ] Tynn ut til ca. **25–30 cm** mellom gjenværende planter
5. [ ] Fjern gamle, brune blader nederst på plantene du beholder

## Mål etter opprydding

| Areal | Mål |
|-------|-----|
| Jordbær | Én tydelig rad/bånd, 25–30 cm mellom planter, ingen utløpere utenfor |
| Bringebær | 6–8 friske grønne kaner per meter, brune kaner fjernet etter avling, kaner bundet inn |
