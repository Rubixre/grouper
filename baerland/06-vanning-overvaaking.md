# Vanning og overvåking

Jevn fuktighet og tidlig oppdagelse av problemer gir mer avling enn «ekstra» gjødsel.

## Vanning

### Prinsipper

- [ ] Hold jorden **jevn fuktig** i blomstring og modning
- [ ] Vanne **om morgenen**, direkte på jorden — ikke over bladene
- [ ] I tørre perioder: grundig vanning **1–2 ganger per uke** (eller dryppvanning)

### Hvorfor jevnhet er viktig

| Problem | Årsak |
|---------|-------|
| Små / dårlige bær | For lite vann i modning |
| Sprukne jordbær | Ujevn vanning (tørt → plutselig mye vann) |
| Mer sopp | Våte blad over natten |

### Enkel rutine

1. [ ] Stikk fingeren 3–5 cm ned i jorden — er det tørt? Vanne.
2. [ ] Prioriter vanning under blomstring og når bærene sveller
3. [ ] Etter mulch: sjekk under mulchen; overflaten kan se tørr ut mens jorden er fuktig

## Skadedyr og sykdom — oversikt

| Problem | Tegn | Tiltak |
|---------|------|--------|
| **Gråskimmel** (jordbær) | Grå belegg på bær og blad | God lufting, fjern infisert materiale, klipp/renover |
| **Bringebærtrips** | Sølvhvite flekker på blad | Fjern angrepne skudd, vann undersiden av blad |
| **Jordbærmidd** | Hull / skadet blad | Fjern ugress, vurder tiltak ved kraftig angrep |
| **Fugler** | Bær forsvinner | Nett over radene fra modning |

## Ukentlig sjekk (5–10 minutter)

- [ ] Fjern råtne bær og syke blad
- [ ] Se etter grå belegg på jordbær
- [ ] Se etter sølvflekk / deformerte bringebærblad
- [ ] Sjekk at mulch ikke ligger kvelende rundt jordbærkronen
- [ ] Sjekk at grønne bringebærkaner fortsatt er bundet inn

## Forebygging (viktigste medisinen)

Tetthet og gammelt materiale er hovedårsaken til problemer i overvokste bed.

1. [ ] Hold 25–30 cm mellom jordbærplanter
2. [ ] Hold 6–8 bringebærkaner per meter
3. [ ] Fjern dødt materiale fra bakken
4. [ ] Bruk mulch for å holde bær rene og jord fuktig

## Når du bør gripe inn raskt

- Flere jordbær med grått belegg → fjern dem samme dag, tynn bladverk
- Bringebærkaner som plutselig visner → klipp bort og fjern fra bedet
- Fugler tar mye → sett nett før neste modningsbølge
