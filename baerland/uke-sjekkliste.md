# Arbeidsrekkefølge — de neste 4 ukene

Tilpasset din situasjon: sommerbringebær med støttetråd, gamle utvokste jordbær.

| Uke | Bringebær | Jordbær |
|-----|-----------|---------|
| **1 (nå)** | Høst modne bær. Bind inn grønne kaner. Fjern døde kaner. | Marker bed-grense. Fjern planter og utløpere utenfor. Tynn ut til 25–30 cm. |
| **2** | Fortsett høsting. Tell kaner — for mange grønne? Noter. | Fjern svakeste/gamle planter innenfor bedet. |
| **3 (etter avling)** | **Klipp bort alle brune kaner.** Behold 6–8 grønne per meter. | **Jordbærklipping** — klipp ned til 5–10 cm. Fjern materiale fra bakken. |
| **4** | Bind inn grønne kaner på nytt. Kompost + mulch (5–8 cm). | Kompost + mulch (halm/strø, 3–5 cm). Planlegg ny rad til våren 2027. |

## Uke 1 — detaljert sjekkliste

### Bringebær
- [ ] Høst det som er modent
- [ ] Bind inn grønne kaner på støttetråd
- [ ] Fjern tørre/syke kaner
- [ ] Sjekk at trådene er stramme

### Jordbær
- [ ] Marker ønsket grense
- [ ] Fjern alt utenfor grensen
- [ ] Tynn til 25–30 cm
- [ ] Fjern råttent materiale fra bakken

## Uke 2 — detaljert sjekkliste

### Bringebær
- [ ] Fortsett høsting
- [ ] Tell grønne kaner per meter
- [ ] Merk om du må tynne etter avling

### Jordbær
- [ ] Fjern svakeste planter
- [ ] Noter om noen planter er friske nok til eventuelt test-utløpere (valgfritt)

## Uke 3 — detaljert sjekkliste (etter avling)

### Bringebær
- [ ] Klipp alle brune kaner til bakken
- [ ] Behold 6–8 grønne per meter
- [ ] Fjern overskytende grønne kaner

### Jordbær
- [ ] Jordbærklipping til 5–10 cm
- [ ] Fjern klippet materiale

## Uke 4 — detaljert sjekkliste

### Begge
- [ ] Kompost rundt plantene
- [ ] Mulch: 3–5 cm jordbær, 5–8 cm bringebær
- [ ] Etabler enkel vanningsrutine
- [ ] Skriv ned plan for ny jordbærrad våren 2027
