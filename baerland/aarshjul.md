# Årshjul (typisk norsk klima)

Referanse for Østlandet / innland. Juster 1–2 uker tidligere på mild kyst, senere i kaldere strøk.

## Vår (mars–mai)

### Begge
- [ ] Fjern vinterbeskyttelse og gammelt mulch forsiktig
- [ ] Gjødsle lett (kompost + litt nitrogen)

### Bringebær
- [ ] Sjekk / reparer støttetråd
- [ ] Bind inn overvintrede kaner (de som var grønne i fjor, nå brune)
- [ ] Fjern kaner som er knust av snø/frost

### Jordbær
- [ ] Plant ut nye planter ved fornyelse (april–mai)
- [ ] Fjern vinterskadde blader

## Sommer (juni–august)

### Jordbær
- [ ] Høst sommerjordbær
- [ ] Klipp / renover etter avling (5–10 cm)
- [ ] Legg ny mulch (3–5 cm)

### Bringebær (sommersort)
- [ ] Høst juni–juli fra brune kaner
- [ ] Bind inn årets grønne kaner underveis
- [ ] Klipp bort fruktede (brune) kaner etter avling
- [ ] Behold 6–8 grønne kaner per meter

### Begge
- [ ] Luk ugress (lettest med mulch på plass)
- [ ] Vanne i tørke
- [ ] Overvåk gråskimmel og trips

## Høst (sept–okt)

- [ ] Ekstra mulch før vinteren
- [ ] Rydd bort sykt materiale
- [ ] Plant nye bringebær om nødvendig
- [ ] Planlegg jordbærfornyelse til neste vår

> Merk: Høstbringebær (klipp alle kaner om vinteren) gjelder **ikke** deg — du har sommerbringebær.

## Vinter (nov–feb)

- [ ] Beskytt unge jordbærplanter med halm/strø ved hard frost
- [ ] Sjekk at støttestolper står stødig
- [ ] Bestill / planlegg nye jordbærplanter hvis du fornyer om våren
