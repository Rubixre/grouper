# Fase 1: Kartlegging

Bruk dette skjemaet én gang nå, og gjerne igjen hver vår.

## Status (utfylt)

| Sjekk | Jordbær | Bringebær |
|-------|---------|-----------|
| Type / sort | Sommerjordbær (antatt) | **Sommerbringebær** (bekreftet) |
| Tetthet | Overvokst / utvokst | Skal tynnes til 6–8 kaner per meter |
| Alder | **Mange gamle planter** | Etablerte kaner (grønne + brune) |
| Skader | Ukjent — sjekk for brune/bladløse planter og gråskimmel | Sjekk for tørre, sprukne eller syke kaner |
| Struktur | Noen planter **vokst ut av plassen** | **Støttetråder på plass** |
| Ugress | Luket bort | Luket bort |

## Hva brune vs. grønne kaner betyr (sommerbringebær)

| Kanetype | Hva den er | Hva du gjør |
|----------|------------|-------------|
| **Brune** | Fjorårets vekst som bærer frukt *nå* (juni–juli) | Høst bærene, deretter klipp kanene bort |
| **Grønne** | Årets nye vekst | Behold og bind inn — de bærer *neste* sommer |

## Beslutning etter kartlegging

- Bringebær: **sommersort** → klipp brune kaner *etter* avling, behold grønne
- Jordbær: **gamle + utvokste** → rydd hardt nå, planlegg ny rad våren 2027
